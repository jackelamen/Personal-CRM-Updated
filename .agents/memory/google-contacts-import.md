---
name: Google contacts import
description: Platform integration availability and the supported import boundary for this product
---

Direct Google Contacts/People API OAuth is not available in the current integration inventory. The supported path is importing a Google Contacts CSV or vCard export locally.

**Why:** The available Google connectors cover Calendar, Docs, Drive, Gmail, and Sheets, but not Contacts/People.

**How to apply:** Keep contact importing local-first unless a Google Contacts/People API integration is explicitly added.
